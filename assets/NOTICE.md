# 에셋 출처와 권리 (NOTICE)

이 폴더의 게임 이미지는 **비상업적 연구·개인 학습 목적**으로만 사용한다.
상업적 이용, 재배포, 2차 저작물 제작을 허가하지 않는다.

| 폴더 | 내용 | 원 출처 |
|---|---|---|
| `monsters/` | 몬스터 스프라이트(투명 PNG) | 천하제일상 거상 인게임 그래픽 — GoGo-Lap 거상 도감(https://gogolap.com/gersang/db/monster) 정리본 |
| `items/` | 드랍 아이템 아이콘 | 위와 같음 |
| `negatives/` | 학습 대상이 아닌 다른 몬스터 스프라이트 | 위와 같음 |
| `backgrounds/` | 실제 사냥 화면 크롭 + 절차적 지형 텍스처 | 크롭 원본: 해해(haehaegame.tistory.com)·문성(moon-seong.tistory.com) 공략 스크린샷 / 절차적 텍스처: 이 저장소 코드로 생성 |
| `screenshots/` | 배경 크롭 원본 스크린샷 | 위 블로그 공략글 |
| `../test_images/` | 검수용 실제 사냥 화면 | 해해·문성·쀼뿝(mhss.tistory.com) 공략 스크린샷 |

- 게임 이미지의 저작권은 **AK 인터랙티브 / 그라비티**에 있다.
- 스크린샷 저작권은 각 블로거에게 있다. 권리자의 요청이 있으면 해당 파일을 즉시 삭제한다.
- 스프라이트 파일명(`python_100` 등)은 원본 사이트의 키를 그대로 쓴 것이며, `manifest.json` 에 파일별 출처 URL이 기록되어 있다.
