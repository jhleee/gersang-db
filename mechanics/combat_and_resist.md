# 전투 · 저항 · 속성 계산 정리

이 문서는 거상의 데미지 계산에 쓰이는 공식과 커뮤니티에서 검증된 수치를 모은 것이다.
공식(게임사)이 명시한 문서가 아니라, 다수의 커뮤니티 자료에서 같은 값으로 교차 확인된 정리임을 먼저 밝혀 둔다.
몬스터 수치는 [`data/monsters.json`](../data/monsters.json) 과 각 던전 문서에서 가져다 쓸 수 있다.

- 작성 기준일: 2026-11-09
- 관련 문서: [속성 상성표](../README.md#속성-상성), [던전 디렉터리](../dungeons/dungeon_directory.md)

---

## 1. 저항 → 피해 감소율 (거상 저항 공식)

거상의 스탯창 저항력(%)은 그대로 데미지를 깎지 않는다. 저항력을 실제 감소율로 바꾸는 식이 따로 있다.

```
피해 감소율(%) = 0.16 × 저항력(%) + 57
받는 피해 배율   = 1 - (0.16 × 저항력 + 57) / 100
```

- 저항 0%에서도 57%가 깎이므로, 저항 0 몬스터를 때리면 표기 데미지의 **43%** 만 들어간다.
- **상한은 98.6%** 이고, 이 값은 **저항 260%** 에서 나온다(`0.16 × 260 + 57 = 98.6`). 260%를 넘겨 올려도 받는 피해는 1.4% 아래로 내려가지 않는다.
- 상한 이후의 저항은 몬스터의 저항 감소 디버프를 상쇄하는 용도로만 의미가 있다(아래 3절).
- 이 식은 **내가 몬스터를 때릴 때와 몬스터가 나를 때릴 때 모두** 같은 형태로 적용된다.

| 저항력 | 피해 감소율 | 실제 들어가는 피해 |
|---|---|---|
| 0% | 57.0% | 43.0% |
| 40% | 63.4% | 36.6% |
| 100% | 73.0% | 27.0% |
| 150% | 81.0% | 19.0% |
| 200% | 89.0% | 11.0% |
| 220% | 92.2% | 7.8% |
| 250% | 97.0% | 3.0% |
| 260% | 98.6% | 1.4% |
| 270% 이상 | 98.6%(상한) | 1.4% |

> 고저항 구간일수록 저항 1%p의 가치가 커진다. 250%→240%는 받는 피해가 3.0%→4.0%로 **1.33배**가 되지만,
> 260%→250%는 1.4%→3.0%로 **2.14배**가 된다.

**출처**: 거상 저항력 공식과 그 효과(네이버 블로그, 2015) / [거상]저항력에 대한 기본적인 정리(네이버 블로그, 2016) / 거상 저항에 따른 효율성 계산법(DC인사이드 거상M 갤러리, 2024) — 세 자료의 식과 260% 상한이 일치한다.

## 2. 저항과 방어력의 차이

- 거상에서 **방어력은 데미지 감소와 무관**하다. 피해를 줄이는 값은 타격저항·마법저항뿐이다.
- **타격저항**은 타격 계열 스킬/평타를, **마법저항**은 마법 계열 스킬을 깎는다. 서로 대체되지 않는다.
  마법저항이 아무리 높아도 타격 계열 피해는 줄지 않는다.
- 몬스터의 경우 몬스터 정보창의 타격저항/마법저항이 그대로 위 식에 들어간다. 본 DB의 `타저` / `마저` 열이 이 값이다.

## 3. 저항 감소(저깍)와 그 중첩

### 3-1. 유저가 쓰는 저항 감소 스킬

| 스킬 | 깎는 저항 | 감소량 공식 | 250레벨 기준 |
|---|---|---|---|
| 주박청음 | 마법저항 | `floor(레벨 ÷ 5 + 1)%` | 51% |
| 허영갑주 | 타격저항 | `floor(레벨 ÷ 5 + 1)%` | 51% |
| 주박청음-强 | 마법저항 | `floor(레벨 ÷ 4.1 + 1)%` | 61% |
| 허영갑주-强 | 타격저항 | `floor(레벨 ÷ 4.1 + 1)%` | 61% |

- 소수점은 버림. 200레벨 일반 주박 = `floor(41+1)` = 41%, 205레벨 강주박 = `floor(51)=51%`.
- 레벨이 오르면 감소량뿐 아니라 **시전 거리·범위·지속시간**도 늘어난다.
- 봉명음(무기 주작): 타격저항·마법저항을 각각 **15%** 감소. 시전자 레벨과 무관하게 고정이며, 주박/허영과 **별개로 중첩**된다. 공중 몬스터에게는 적중하지 않는다.
- 그 밖의 단발 저항 감소: 각성 아르주나 25%(레벨 비례), 광목천왕 충돌 특성 15%, 각성 도올 '풍룡의 숨결' 타격저항 10%(15초), 대위덕명왕 10%, 부동명왕 파동진 20% 등.

### 3-2. 중첩 규칙

- 유저가 거는 저항 감소는 **합연산**으로 겹친다.
  예: 몬스터 저항 290% − 주박 51% − 봉명음 15% − 지국천왕 화상특성 15% = **209%**.
- 그래서 저항 260%대 몬스터에게 저깍을 몰아 넣으면 딜이 급격히 오른다.
  - 저항 260% 몬스터: 받는 피해 1.4%
  - 같은 몬스터에 주박 51% 적용 → 저항 209% → 감소율 `0.16×209+57 = 90.44%` → 받는 피해 **9.56%** (약 **6.8배**)

### 3-3. 몬스터가 유저에게 거는 저항 감소

- **허영갑주 / 주박청음(몬스터판)**: 저항을 **30%p** 깎는다(260 → 230). 그래서 "풀저항 290%" 라는 말이 나온다(260 + 30).
- **진(眞)허영갑주 / 진주박청음**: 현재 저항의 **30%** 를 비율로 깎는다(260 → 182). 곱연산이라 저항이 높을수록 손실이 크다.
- 저항력 감소형 저주(비율 감소)는 위 두 방식과 적용 방식이 다르므로, 던전별로 어떤 디버프가 오는지 확인해야 한다.
- 실무 기준: **260% = 풀저항**, **290% = 허영/주박까지 고려한 풀저항**. 300%를 넘기면 비율 감소 저주까지 대비된다.

**출처**: 주박청음·허영갑주 레벨별 저항 감소 수치 정리(티스토리, 2023) / 거상 저항 공식_계수(티스토리, 2020) / 거상 - 타격저항 감소 스킬(티스토리, 2021).

## 4. 속성 상성과 속성값 데미지

### 4-1. 상성 순환

```
불(火) → 바람(風) → 뇌전(雷) → 물(水) → 불(火)
(앞 속성이 뒤 속성에게 유리 = 데미지 증가)
```

| 내 공격 속성 | 유리(데미지 증가) | 불리(데미지 감소) |
|---|---|---|
| 불(火) | 바람(風) | 물(水) |
| 바람(風) | 뇌전(雷) | 불(火) |
| 뇌전(雷) | 물(水) | 바람(風) |
| 물(水) | 불(火) | 뇌전(雷) |
| 땅(地) | 전 속성에 추가 피해 | 상성 없음(피격 시 고정 +30%) |

- 무속성 몬스터는 상성 계산에서 제외된다(한쪽이라도 속성이 없으면 속성 데미지 자체가 적용되지 않는다).
- 본 DB의 `속성` 열이 몬스터 속성, `속성값` 열이 그 몬스터의 속성값이다.
  몬스터 속성별 분포는 [README](../README.md#속성-상성) 참고.

### 4-2. 속성값 데미지 공식

`속성값`은 상성 우열과 함께 곱해지는 증감률이다. 최종 데미지 안에서의 위치는 다음과 같다.

```
최종 데미지 = 원본 데미지
            × (1 − 저항에 의한 피해 감소율)
            × (1 ± 속성값에 의한 증감률 + 땅 속성 추가 증가율)
            × (1 ± 기타 버프/디버프 증감)
            × (1 + 2 + 추가 크리티컬 데미지율)
```

속성값 증감률(%)은 다음 규칙으로 정해진다(공격자 A, 피격자 D, 각자의 속성값 `a`, `d`).

| 상황 | 조건 | 증감률 |
|---|---|---|
| 유리한 속성으로 공격 (A→D 우위) | a ≥ d | **+a** % |
| 유리한 속성으로 공격 (A→D 우위) | a < d | **+(a − (d − a)/2)** % (음수면 감소) |
| 불리한 속성으로 공격 (A→D 열위) | — | **−d** % |
| 상성 관계 없는 속성끼리 | a ≥ d | 0% (속성 데미지 없음) |
| 상성 관계 없는 속성끼리 | a < d | **−(d − a) × 1.5** % |
| 땅 속성으로 공격 | — | **+a** % |
| 땅 속성에게 공격 | — | **+30% 고정** |
| 한쪽이라도 무속성 | — | 0% (적용 안 됨) |

- 증감 **감소**는 최대 90%까지로 제한된다(2023-09-21 본섭 패치, 이전 100%).
- 증감 **증가**의 상한은 2023-05-04 패치로 사라졌다(그 전에는 100% 초과분이 잘렸다).
- 예: 불 속성값 20인 캐릭터가 바람 속성값 20 몬스터를 때리면 +20%, 같은 캐릭터가 물 속성값 20 몬스터를 때리면 −20%.
- 예: 불 속성값 30 캐릭터가 바람 속성값 50 몬스터를 때리면 `30 − (50−30)/2 = +20%`.

**출처**: 거상 속성값에 의한 속성 데미지 공식(네이버 블로그 '거상노트', 2024-12) / 거상 속성 상성표(kakao.gg GG FACTORY 도구, 커뮤니티 정설 교차검증 명시).

> 주의: 표마다 "속성값"과 "저항"을 섞어 표기하는 경우가 많다. 본 DB에서 `속성값`은 몬스터가 가진 **공격 속성 세기**(예: 20, 350)이고,
> `타저`/`마저`는 **피해 감소 저항**(예: 260, 450)이다. 둘은 다른 값이며 서로 대체되지 않는다.

## 5. 상재(商才) 계산

조선 여성 캐릭터가 1차 전직할 때 얻는 특성으로, 상점이 취급하지 않는 아이템을 **30% 더 비싸게** 판다.

- 조건: 특성 트리에서 상재를 **10/10** 까지 찍어야 최대 30%가 적용된다(레벨 180 전후에 완성).
- 계산: `상재 판매가 = 기본 판매가 × 1.3`
  - 예: 청랑의 어금니 기본 50만 냥 → 상재 65만 냥(20개 묶으면 1,000만 → 1,300만 냥).
- 상재가 적용되는 것: 수식어 없는 일반 장비류, 육의전 거래가 없는 재료 아이템(통칭 "상재템").
- 적용되지 않는 것: 각 마을 상점이 취급하는 품목. 그런 품목은 해당 마을에 팔아야 제값을 받는다.
- 사냥 수익 계산: `시간당 수익 = Σ(드랍 수량 × 상재 판매가) ÷ 사냥 시간`. 상재 여부에 따라 같은 드랍이 30% 차이 난다.
- 본 DB의 드랍 목록에는 아이템 이름만 있고 가격은 없다. 가격은 서버 시세에 따라 달라지므로 각 계산기/육의전 시세를 참고해야 한다.

**출처**: 거상 상재 조녀 만들기(네이버 블로그, 2015·2022·2024 정리) / 상재 계산기(거리니닷컴, 거타 계산기).

## 6. 사냥터 판단에 바로 쓰는 계산

1. **처치 타수** = `ceil(몬스터 HP ÷ (내 1타 원본 데미지 × (1 − 몬스터 뎀감률) × (1 + 속성 증감률)))`
   - 몬스터 뎀감률 = `0.16 × (타저 또는 마저) + 57` (내 스킬 계열에 맞는 쪽)
2. **저깍 후 타수** = 같은 식에 `저항 − 저깍` 을 넣어 다시 계산. 260% 몬스터는 저깍 51%만 걸어도 딜이 약 6.8배가 된다.
3. **속성 선택**: 몬스터 속성의 "불리" 속성으로 공격(예: 불 몬스터 → 물 속성). 몬스터 속성값이 높을수록 상성 이득이 커진다.
4. **EXP 효율**: `EXP ÷ HP` 가 높은 몬스터가 시간당 경험치가 좋다. 던전별 집계는 [던전 디렉터리](../dungeons/dungeon_directory.md) 참고.
5. **드랍 파밍**: 아이템 이름으로 역검색하려면 [드랍 역색인](../items/key_drops.md) 또는 `data/drops_index.json` 을 쓴다.
